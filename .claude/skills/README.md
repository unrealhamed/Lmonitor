# Claude Code skills

UI design and animation skills by Emil Kowalski, copied from
https://github.com/emilkowalski/skills (commit c8a79627b59d72d764d6ab6f2c87c09a48169833).
MIT licensed; see `LICENSE-emilkowalski-skills`.

The skills target the web (CSS/React). For Lmonitor's Qt/QML interface (`lmonitor/qt/qml`),
apply the principles (easing, duration, purpose of motion, choreography, worst-case data)
and translate the APIs: CSS `transition`/`ease-out` -> QML `Behavior`/`NumberAnimation` with `Easing.OutCubic` etc.

Included: animate, animation-performance, animation-vocabulary, apple-design, break-ui,
choreograph, emil-design-eng, find-animation-opportunities, improve-animations,
remove-animations, review-animations.

Not included (not applicable to this project): animate-expo, ask-sonner, mobile-native,
pick-ui-library, prototype, write-swift.
