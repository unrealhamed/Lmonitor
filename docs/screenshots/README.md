# Screenshots

Real screenshots of Lmonitor v1.17.7, taken on the author's laptop with administrator rights.
The Windows user name and PC name are replaced by "Player" / "GAMING-PC".

| File | What it shows |
|---|---|
| `dashboard.png` | Home page |
| `graphs.png` | Graphs page (real time) |
| `overlay-settings.png` | Overlay page with the live preview |
| `graph-overlay.png` | Graph overlay page |
| `graph-overlay-hud.png` | the graph overlay itself (cut from the preview) |
| `personalize.png` | Personalize page (themes, colors, size) |

## Taking new ones
1. Start Lmonitor, press `Win + Shift + S`, select the window and save the picture here as PNG.
2. Crop out anything private (your user name, other windows, the list of startup programs).
