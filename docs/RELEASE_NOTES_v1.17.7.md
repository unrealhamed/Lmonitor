# Lmonitor 1.17.7

A small update to 1.17.6.

- Every chart (Home, Graphs and both graph overlays) now has two time spans only: **Real time** (the last 10 seconds, 4 readings a second) and **1 minute**. Real time is the default; an older saved span switches to real time.
- Home: a **Graph overlay** switch next to the Overlay switch.
- Home: the overlay box became **Right now** - the game in front, its frame rate, the session recorder, your last session and the anti-cheat safe mode state. The overlay settings that were there are on the Overlay page.
- New screenshots.

Not verified by the author: the Right now box with a real game in front.

## Install
Download `Lmonitor_Setup_1.17.7.exe` below and run it. It updates an older version in place and keeps your settings.
