# Lmonitor 1.18.6

Everything since 1.18.3.

## New
- **What's new box:** after an update that added something, a box opens once in the middle of the window (the window behind it goes out of focus) and shows each change with a small animation. *Skip* closes it; **About > What's new** opens it again. A new install does not show it.
- **Network usage, easier to read:** the chosen day is now a list - one line per hour that had traffic (`16:00 - 17:00`, `4 PM`, the amount, a bar, download / upload), the current hour is marked *now*, and a click on an hour lists its programs. Each day's total is written above its bar.

## Fixed
- Real-time charts showed a hole of about 2 seconds after going from the *Graph overlay* page to another page and back to *Graphs*.

Not verified by the author: the What's new box in the installed app (checked from source and with the built program in a hidden window).

## Install
Download `Lmonitor_Setup_1.18.6.exe` below and run it. It updates an older version in place and keeps your settings.
